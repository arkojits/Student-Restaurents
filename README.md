# Student-Restaurents

A web application for the Web Application Development course.

The application displays student restaurants in Finland and allows users to view daily and weekly menus.

## Features

- Restaurant list
- Search restaurants by name
- Filter restaurants by city
- Filter restaurants by service provider
- View daily menu
- View weekly menu
- Responsive design
- Real restaurant data from Metropolia REST API

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- REST API

## API

The application uses the Metropolia restaurant API:

`https://media2.edu.metropolia.fi/restaurant/api/v1`
